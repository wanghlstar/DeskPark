# DeskPark 飞牛 FPK 打包计划

**目标：** 将合并后的 DeskPark 打包为可手动安装的飞牛原生应用，并通过 GitHub Actions 生成 APK 和 FPK。

**方案：** 使用飞牛官方 `nodejs_v22` 运行时，包内包含服务端单文件与完整网页资源，`platform=all`。相比 Docker 封装，原生包无需拉取镜像；相比内置 Node.js 二进制，可直接复用系统维护的运行时。

**运行方式：** 使用专用应用用户，监听 8787 端口，桌面图标打开浏览器标签页。飞牛通过 `cmd/main` 管理启动、停止与状态，日志和 PID 写入 `TRIM_PKGVAR`。现有单人存档仍由浏览器保存，联机房间仍在内存中。

**范围：** 新增 `packaging/fnos/`、`scripts/build-fpk.mjs`、`scripts/test-fpk.mjs`、`.github/workflows/fnos.yml` 和安装文档。保持游戏、服务端和路由接口不变。

1. 添加 FPK 服务生命周期集成测试，先验证缺少打包入口时失败。
2. 实现 manifest、包用户权限、桌面入口及服务管理脚本。
3. 复用现有亭子图标，构建脚本复制网页、服务端及许可证，用官方 fnpack 1.3.3 生成包。
4. 验证真实服务的健康检查、网页、WebSocket、重复启动、停止、失效 PID 和端口冲突。
5. 新增 Actions：安装 Node.js 22，执行项目检查、构建和 FPK 测试，上传 `.fpk` 与 SHA-256 测试产物。Android 继续使用已有工作流。
6. 检查完整差异并记录实际验证范围。没有飞牛测试设备时，不声称完成 NAS 实机安装验证。

**工具：** 官方文档 <https://developer.fnnas.com/docs/guide/>；fnpack <https://developer.fnnas.com/docs/cli/fnpack/>。首次提供未签名的手动测试包（`fnpack build --nosign`），不包含开发者私钥。
