# APK 运行时服务器设置

目标：安装同一个 APK 后，在大厅「设置 → 联机服务器」填写地址，无需重新打包。

- 保存规范化后的 HTTP / HTTPS 服务地址，支持直接粘贴 WebSocket `/ws` 地址或填写 IP 与端口。留空恢复安装包默认地址；没有预设时仍可单人游戏。
- 联机 WebSocket、邀请链接、服务器默认 AI 和自定义 AI 转发统一使用所选服务器。连接测试使用临时身份完成 DeskPark 握手，不占用玩家连接。
- 保存后刷新应用，关闭旧连接并重新读取默认 AI；保留单人存档、昵称和自定义 AI。自选服务器时使用内置页面，避免被旧构建参数重定向。
- Android 保留 HTTPS 本地 origin，允许连接用户指定的 HTTP / WS 局域网服务。无需放开外部网页导航。

实施与验证：

1. 先测试地址校验、持久化、覆盖顺序、邀请与 AI 一致性、外壳跳转和连接握手。
2. 接入设置界面与 Android 配置，更新安装指南。
3. 运行项目检查、生产浏览器双端联机、服务器切换与默认 AI 验证，检查 FPK 和 APK 配置。
4. 通过 Actions 发布 `v0.3.4-alpha.1` 并核验附件。
