# 飞牛本地 AI 与普通麻将实施计划

**目标：** 飞牛可向管理员指定的本地 AI 接口转发请求，并新增带字牌的 136 张普通麻将。

## 本地 AI

- 保持默认公网代理限制；通过 `AI_PROXY_ALLOWED_TARGETS` 指定可用的完整接口基址，逐个匹配协议、主机、端口和路径。
- 指定地址支持 HTTP 和自定义端口；仍仅允许固定的模型补全端点，不保存 Key。
- 飞牛安装和应用设置提供可选的 AI 地址字段，启动时传入代理配置。网页里的接口、Key、模型仍由玩家填写；使用本地 AI 时开启「经服务器转发」。
- 验证：未配置时保持拒绝；指定地址实际收到补全请求、鉴权和正文；其他内网地址或路径仍拒绝；上游 401 原样返回。

## 普通麻将

- 独立大厅玩法「普通麻将」，复用现有 136 张牌面、胡牌判断和四人牌桌。
- 万条筒和东南西北中发白，无花牌、无癞子、不吃；可碰、明杠、暗杠、补杠。
- 四组面子加一对即可胡，支持点炮和自摸，一家胡牌即结束本盘；多人可胡同一张时按出牌顺序截胡。
- 不换三张、不定缺、不设次牌，不设复杂番型或抢杠。点炮由出牌人付 1 分，自摸其余三家各付 1 分，杠只补牌、不另计分；荒庄不计分。
- 验证：发牌与牌数守恒、胡牌和碰杠优先级、补牌、结算、信息隐藏、非法动作、电脑完整模拟、单人和联机界面。

## 执行与交付

1. 先写本地 AI 代理回归测试，再实现允许列表和飞牛配置。
2. 先写普通麻将规则测试，再接入规则、AI 候选和界面。
3. 运行 `npm run format:check`、`npm run check`、`npm run build:fpk` 和浏览器验证。
4. 审查完整差异，提交并推送 `v0.3.1-alpha.1`；由 Release Actions 构建 FPK 与 APK 并统一创建预发布。
