# APK 牌桌强制横屏

**目标：** 设置中提供可保存的牌桌强制横屏开关，默认关闭。

**方案：** 使用 Capacitor 8 官方 Screen Orientation 插件，由平台层调用原生 `lock(landscape)` / `unlock()`。单人及联机牌桌跟随本机设置；大厅和联机等待区恢复系统方向。关闭开关即时解锁。浏览器和旧 APK 显示可用性说明，不请求全屏或改变界面坐标。

1. 先验证原生调用参数、旧设置兼容、持久化及失败传播。
2. 加入开关与路由同步，在生产浏览器中模拟原生桥验证进入、关闭、返回、重启和联机。
3. 同步插件并检查 Android 注册；运行项目检查、FPK 服务测试和生产资源兼容检查。
4. 通过 Actions 发布 `v0.3.7-alpha.1`，核验 APK 原生插件、两种附件内容与 SHA-256。手机旋转效果需实机验收。
