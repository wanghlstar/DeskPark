# 棋牌背景音乐

**目标：** 为网页、APK 和飞牛版本加入离线可用的原创棋牌背景音乐，保持现有音效与语音开关独立。

**方案：** 两首原创五声音阶小曲，轻快曲用于大厅与扑克，舒缓曲用于麻将与棋类。用 Web Audio 离线合成笛音、拨弦、低音和轻打击，缓存为循环音频，播放时不依赖网络、文件下载或持续的 JavaScript 节拍器。首次交互后才能播放，切到后台暂停，回到前台恢复；切换曲目淡入淡出。音乐默认开启、音量 20%，单独保存开关和音量，旧版设置自动补默认值。

1. 先用真实浏览器复现缺少音乐设置；再实现两首曲目、播放器和场景切换。
2. 在大厅设置与牌桌外观中加入独立音乐开关和音量，保留音效开关。
3. 验证真实音频缓冲非静音、无削波、循环边界平滑，检查调音量、关闭、后台暂停、离线与快速切换不会重复播放。
4. 运行项目检查、手机横竖屏和 FPK 验证，更新说明，通过 Actions 发布 v0.3.5-alpha.1，并校验正式 FPK/APK 附件。
