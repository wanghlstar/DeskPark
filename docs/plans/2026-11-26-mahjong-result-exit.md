# 麻将结算返回修复

**目标：** 普通麻将打完设定盘数后可以直接返回大厅，共用流程的河洛杠次同步修复。

**原因：** 胡牌、荒庄一律进入 `roundOver`，最后一盘也要四家再准备才结束本场；不可关闭的局间弹窗没有退出入口。

1. 先复现最后一盘只有「继续下一盘」，补充引擎最终结算、荒庄、局间准备、不限盘数与旧状态的回归测试。
2. 最后一盘直接进入 `matchOver`；每盘结算始终提供返回入口，旧状态的继续按钮显示「查看总分」。
3. 验证单人 1/4/8 盘、手机横竖屏、存档清理与续局，及真实联机的房主、客人、观战退出和房主重开。
4. 完成项目与 FPK 检查，通过 Actions 发布 `v0.3.8-alpha.1`，核对正式 FPK、APK 及 SHA-256。
