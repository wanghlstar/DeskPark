# DeskPark v0.3.2-alpha.1

本次 Alpha 增加服务器默认 AI 配置，玩家可直接使用后台模型，也可继续使用自己的 AI。保留上一版的 136 张普通麻将、本地 AI 转发与自定义访问端口。

## 配置服务器默认模型

1. 安装或升级 `deskpark-0.3.2.fpk`。
2. 安装时可填写可选 AI 配置；已安装时打开 **飞牛应用中心 → 闲亭 DeskPark → 设置**。
3. 填写协议（OpenAI 兼容 / Anthropic）、完整地址、API Key 和模型 ID。例如 OpenAI 兼容地址为 `http://192.168.2.8:19020/v1`，Key 和模型 ID 使用 AI 服务实际提供的值。
4. 保存后，在网页 **设置 → AI 人机 → 服务器默认** 点击「测试连接」，玩家无需再填 Key 和模型。保存配置会重启正在运行的服务，当前联机房间会结束。

不需要 AI 时可以留空；地址和模型均填写后才启用默认模型，无需鉴权的接口可不填 Key。Key 只在服务器使用，网页只读取可用状态、协议和模型。应用说明和网页帮助已补充配置入口。

## 玩家自己的配置

网页选择 **自定义**，即可使用各设备自己的协议、地址、Key 和模型，旧配置会保留。切换到服务器默认不会删除它们。

**「经服务器转发」仍使用玩家自己的配置。** 它只解决浏览器直连的网络或跨域问题；使用后台模型请明确选择「服务器默认」。只填过本地地址的 `0.3.1` 配置继续支持自定义转发。

单人对局由浏览器组织局面和处理模型结果，选择服务器默认时由服务器调用 AI；联机电脑目前仍使用服务端内置规则策略。

## 下载与安装

- **飞牛：** 下载 `.fpk`，通过应用中心手动安装或升级；包内版本为 `0.3.2`，依赖 Node.js 22，保留安装时填写的访问端口。此为未签名的 Alpha 测试包。
- **Android：** 下载 `.apk` 安装。此为调试签名的 Alpha 测试包；未设置远程服务器时使用内置单人版。
- 每个文件附有 SHA-256 校验文件，均由 GitHub Actions 构建并发布。使用说明见 [飞牛安装指南](https://github.com/wanghlstar/DeskPark/blob/main/docs/FNOS.md)。

## 验证

327 项项目测试与 9 项 FPK 服务测试通过。浏览器覆盖 OpenAI 兼容和 Anthropic 默认调用、玩家自定义转发、旧配置迁移、手机横竖屏以及未配置时的提示；后台 Key 不出现在浏览器配置、存储或请求中。飞牛向导新增字段的实机显示仍需安装后验收。
