# DeskPark v0.3.5-alpha.1

加入 **原创棋牌背景音乐**，适用于网页、Android APK 和飞牛客户端。

## 两种棋牌氛围

- **大厅与扑克：** 轻快的五声音阶小曲，约 71 秒，笛音与拨弦轮换、低音及轻打击伴奏。
- **麻将与棋类：** 舒缓小曲，约 91 秒，旋律留白更多、打击更轻。
- 随玩法自动切换、淡入淡出，曲目可平滑循环；同一类玩法间切换不重启音乐。
- 音乐在本机合成并缓存，不依赖在线音频资源，离线也可播放。

## 开关与音量

1. 第一次点击或按键后开始播放，默认开启、音量 **20%**。
2. 在 **大厅 → 设置** 或 **牌桌 → 外观** 中找到「背景音乐」与「音乐音量」。设置保存在本机。
3. 音乐音量归零或关闭开关即停止；与「音效」开关独立，出牌音效及报牌语音可单独保留。
4. 切到后台暂停，回到前台恢复；快速切换场景或合成期间关闭音乐，不会触发过期播放或重复循环。

## 升级

- 保留上版 APK 的服务器地址设置、全部玩法、单人存档与 AI 配置。
- APK 连接飞牛时，在 **大厅 → 设置 → 联机服务器** 填游戏地址，测试后保存。好友填写同一服务地址即可通过房间号加入。
- 飞牛后台的端口和服务器默认 AI 配置沿用，升级会结束内存中的联机房间。

## 下载与验证

- **Android：** 下载 `.apk`，为调试签名的 Alpha 测试包。
- **飞牛：** `deskpark-0.3.5.fpk`，依赖 Node.js 22，仍为未签名的手动安装测试包。
- 附件由 GitHub Actions 构建，附 SHA-256 校验文件。
- 验证包括播放器生命周期回归测试、真实浏览器音频合成与循环边界、音量和开关持久化、后台暂停与离线恢复、手机横竖屏，以及项目检查和 FPK 服务测试。Android 由 Actions 构建，具体手机的扬声器、系统静音与音频中断行为待实机体验。
