# DeskPark v0.3.3-alpha.1

本次 Alpha 新增 **五子棋、跑得快、黑白棋**，三款均可单人对电脑、创建联机房间，以及在单人局启用大模型接管。保留已有普通麻将、服务器默认 AI、自定义模型与飞牛自定义端口。

## 三款新游戏

- **五子棋**：15×15 自由规则，黑先、至少五连获胜，长连有效、无禁手。三档内置电脑，人机可悔棋，支持胜利连线、末手标记和落子记录。
- **跑得快**：三人 48 张，每人 16 张，无王，三张 A、一张黑桃 2。黑桃 3 先出，首手必须包含；有大必压（含炸弹），领出单张且下家报单时须出最大单张。支持三带任意两张、两连对、顺子、三顺、飞机及炸弹，不含三带一或四带二。赢家收剩牌分，16 张未出者双倍，炸弹不另计分；有提示、报单和多局积分。
- **黑白棋**：标准 8×8，八方向夹吃翻转；没棋可走自动让行，双方都不能走时按子数判胜。可落位置提示、实时子数、三档内置电脑和人机悔棋。

打开大厅，在「扑克」找到跑得快，在「棋类」找到五子棋和黑白棋。手机横竖屏均可操作；联机时服务器校验每一步，跑得快只向玩家发送自己的手牌。

## 内置电脑与 AI

三款都自带本地策略，无需 API。单人局若要用大模型，在网页 **设置 → AI 人机** 选择「服务器默认」或「自定义」，再点电脑头像旁的 **✨** 开启接管。大模型只能选择合法候选，失败后回退内置电脑。联机电脑使用服务器内置策略。

飞牛安装时或 **应用中心 → 闲亭 DeskPark → 设置** 可填写可选的协议、接口地址、Key 与模型，作为服务器默认；「经服务器转发」仍表示转发玩家自己的配置。详见 [飞牛安装指南](https://github.com/wanghlstar/DeskPark/blob/main/docs/FNOS.md)。

## 下载与升级

- **飞牛：** 下载 `deskpark-0.3.3.fpk`，通过应用中心手动安装或升级，依赖 Node.js 22。沿用已设置的访问端口与 AI 配置；升级会结束当前内存中的联机房间。这是未签名的手动安装测试包。
- **Android：** 下载 `.apk` 安装，这是调试签名的测试包。未配置远程服务器时，三款游戏也包含在内置单人版中。
- 附件由 GitHub Actions 构建，各附 SHA-256 校验文件。五子棋与跑得快的 MIT 来源声明随所有安装包分发。

## 验证

验证覆盖规则边界、多种子完整电脑对局、AI 候选合法性、畸形动作、手机横竖屏、两个独立浏览器联机同步，以及真实模型请求流程的模拟接口。FPK 继续执行真实服务启停、端口、HTTP / WebSocket 和服务器默认 AI 配置测试。
