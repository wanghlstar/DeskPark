# DeskPark v0.3.4-alpha.1

APK 新增 **设置服务器地址**，同一个安装包可连接不同的飞牛或自建 DeskPark 服务。

## 怎么使用

1. 安装新 APK，打开 **大厅 → 设置 → 联机服务器**。
2. 填写游戏服务地址，例如 `http://192.168.2.8:8787`；端口以飞牛安装时设置为准。也支持 HTTPS、直接填写 IP 与端口，或粘贴 WebSocket `/ws` 地址。
3. 点击「测试服务器」，成功后「保存并刷新」。联机、房间邀请、服务器默认 AI 和个人 AI 转发统一使用该服务器。
4. 好友的 APK 也填写同一地址，再通过房间号加入；邀请链接可在浏览器打开。

这是 DeskPark 游戏地址，不是模型 `/v1` 地址。服务器默认模型仍由飞牛管理员在 **应用中心 → 闲亭 DeskPark → 设置** 配置，玩家可选默认或自己的 AI。

## 保存与兼容

- 地址只保存在本机，重启后继续生效。保存会关闭旧联机连接并刷新，保留本机单人存档、昵称和自定义 AI 配置。
- 留空恢复安装包预设；没有预设时仍可使用内置单人游戏。自选服务器后使用内置页面，更新游戏资源需更新 APK。
- 支持局域网 HTTP / WS，好友需要能访问同一服务器。原有 HTTPS / WSS 和构建预设继续支持。
- 保留五子棋、跑得快、黑白棋、普通麻将及已有全部玩法。

## 下载与验证

- **Android：** 下载 `.apk`，为调试签名的 Alpha 测试包。
- **飞牛：** `deskpark-0.3.4.fpk` 包含对应网页客户端，可手动安装或升级；沿用访问端口与 AI 配置，升级会结束内存中的联机房间。依赖 Node.js 22，仍为未签名的手动安装测试包。
- 附件由 GitHub Actions 构建，附 SHA-256 校验文件。
- 验证包括地址与持久化测试、真实 WebSocket 握手、生产网页跨服务联机与切换、邀请链接、服务器默认 AI、手机横竖屏，以及项目检查和 FPK 服务测试。Android 网络配置与打包由 Actions 检查，手机实机连接待安装验收。
