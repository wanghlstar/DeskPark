# DeskPark v0.3.1-alpha.1

本次 Alpha 包含 136 张普通麻将与飞牛本地 AI 转发支持。FPK 和 APK 由 GitHub Actions 构建，通过检查后统一附到本次预发布。

## 普通麻将

- 万、条、筒和东南西北中发白共 136 张，无花牌、无癞子、不吃。
- 碰、明杠、暗杠、补杠、点炮、自摸；四组面子加一对，一家胡即结束本盘。
- 点炮由放炮者付 1 分，自摸其余三家各付 1 分，杠只补牌；不换三张、不定缺、不设次牌和复杂番型。
- 支持单人电脑、联机与单人 AI 接管。

## 飞牛本地 AI

升级 FPK 后，在飞牛应用设置填写「本地 AI 接口」，例如 `http://192.168.2.8:19020/v1`。再在网页 AI 设置中选择 OpenAI 兼容、填写同一地址、有效 Key 和模型，并开启「经服务器转发」。此时由飞牛连接 AI，绕过浏览器直连所遇到的跨域限制。

默认仅允许 HTTPS 公网接口；只有部署者指定的完整基址可以使用 HTTP、内网和自定义端口。Key 保存在玩家浏览器里，服务端不保存。

## 下载与安装

- **飞牛：** 下载 `.fpk`，通过应用中心手动安装或升级；包内版本为 `0.3.1`，依赖 Node.js 22，安装时支持填写访问端口。此为未签名的 Alpha 测试包。
- **Android：** 下载 `.apk` 安装。此为调试签名的 Alpha 测试包；未设置远程服务器时使用内置单人版。
- 每个文件附有 SHA-256 校验文件。使用说明见 [飞牛安装指南](https://github.com/wanghlstar/DeskPark/blob/main/docs/FNOS.md)。

## 验证

310 项项目测试、7 项 FPK 服务集成测试通过；浏览器验证覆盖普通麻将单人、手机横竖屏、点炮 / 自摸结算、双浏览器联机和本地 AI 转发。FPK 安装和应用设置界面仍需在飞牛设备上验收。
