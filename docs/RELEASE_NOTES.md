# DeskPark v0.3.8-alpha.1

修复 **普通麻将结算页无法直接返回大厅**，河洛杠次的共用结算流程同步修复。

## 结算返回修复

- 旧版在最后一盘结束后仍显示「继续下一盘」，要额外准备一次才进入总分；这层结算弹窗又挡住了顶部返回。
- 现在打完设定的 1、4、8 盘后立即显示本场总分，可直接「返回大厅」，或由房主选择「再来一场」。最后一盘荒庄同样正确结束。
- 每盘结算都提供返回入口，普通玩家和观战者均可退出；未打完时仍可继续下一盘，中途退出保留单人进度，完成本场后清除已结束存档。
- 兼容旧版停在最后一盘结算的存档，继续操作显示「查看总分」，也可直接返回大厅。

## 包含牌桌强制横屏

- 安装本版 APK，在 **大厅 → 设置** 或 **牌桌 → 外观** 打开「牌桌强制横屏」。默认关闭，本机保存选择。
- 单人或联机牌桌中自动横屏；关闭、返回大厅或等待区恢复系统方向，无需打开系统自动旋转或网页全屏。
- 河南捉黑 A、全部单人及联机游戏，中文音色、AI 发言朗读、三档对局节奏和原创背景音乐。
- APK 自定义服务器地址、个人 AI、飞牛服务器默认模型以及本机存档和设置。
- 飞牛端口与默认 AI 配置沿用；升级服务会结束当前内存联机房间。

## 下载与验证

- **Android：** `.apk` 为调试签名 Alpha 包，包含强制横屏原生插件；浏览器使用系统自动旋转。
- **飞牛：** `deskpark-0.3.8.fpk` 依赖 Node.js 22，仍为未签名手动安装测试包。网页联机需更新服务端规则。
- 附件由 GitHub Actions 构建，附 SHA-256。检查涵盖最后一盘胡牌与荒庄、局间及不限盘数、旧版状态兼容、单人与真实联机退出、手机横竖屏、项目测试和 FPK 服务测试；手机实际旋转与音色仍需实机体验。
