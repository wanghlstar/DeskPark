# DeskPark v0.3.7-alpha.1

加入 **APK 牌桌强制横屏**，可在设置中开启并保存。

## 开启方式

1. 安装本版 APK，打开 **大厅 → 设置** 或 **牌桌 → 外观**。
2. 打开「牌桌强制横屏」。默认关闭，选择保存在本机，重启后继续生效。
3. 进入单人或联机牌桌自动横屏；在牌桌中开启即时生效，无需打开系统自动旋转或网页全屏。
4. 关闭开关、返回大厅或联机等待区时恢复系统方向，不强制锁定竖屏。

方向切换不重开对局、不清空存档。通过 Capacitor 官方方向插件控制原生窗口；浏览器和没有插件的旧 APK 显示说明且禁用开关。

## 保留已有功能

- 河南捉黑 A、全部单人及联机游戏，中文音色、AI 发言朗读、三档对局节奏和原创背景音乐。
- APK 自定义服务器地址、个人 AI、飞牛服务器默认模型以及本机存档和设置。
- 飞牛端口与默认 AI 配置沿用；升级服务会结束当前内存联机房间。

## 下载与验证

- **Android：** `.apk` 为调试签名 Alpha 包。本次需更新 APK 才能获得原生方向插件。
- **飞牛：** `deskpark-0.3.7.fpk` 依赖 Node.js 22，仍为未签名手动安装测试包。普通浏览器使用系统自动旋转。
- 附件由 GitHub Actions 构建，附 SHA-256。检查涵盖方向调用、设置保存、牌桌进出与联机、项目测试和 FPK 服务测试；Actions 验证原生插件注册。具体手机的实际旋转效果需实机确认。
