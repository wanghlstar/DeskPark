# DeskPark v0.3.6-alpha.1

加入 **河南捉黑 A**，改善中文语音、AI 发言朗读和电脑出牌节奏。

## 河南捉黑 A

- 大厅选择「捉黑 A」，支持 3–8 人；3–4 人一副 54 张、5 人起两副 108 张，含大小王、全部发完，无底牌和进贡。
- 只有黑桃 A 是隐藏身份，两副牌的持有者同队。同一人拿两张则独战；任意黑 A 提前出完同队即赢，其他人全部出完才算捉住黑 A。
- 大小为 **黑桃 A ＞大王＞小王＞3＞2＞其他 A＞K…4**，无炸弹和王炸。出牌近似跑得快，同型同张数比较，可主动过牌；顺子、连对和三顺只使用 4 到普通 A。
- 多人牌桌提供提示、中文报牌、出完顺序、隐藏身份标记、多局积分和局末亮牌。支持单人内置电脑、联机，以及可选的单人 AI 接管。

## 音色与 AI 发言

1. 在 **大厅 → 设置** 或 **牌桌 → 外观** 中选择「中文音色」，调整「语音速度」，点击「试听音色」。优先设备本地普通话；可用音色由手机或浏览器的语音引擎决定。
2. 使用大模型时，先选服务器默认或自定义模型，再在单人局点亮电脑头像旁的 **✨**。
3. 「出牌发言」选择偶尔、适中或话痨；话痨在每次模型思考时请求一句话。只有一种动作时直接出牌，不额外等待模型。
4. 打开「AI 发言朗读」可读出文字气泡，需要同时开启「音效」和「语音播报」。关闭朗读仍显示文字；AI 朗读期间不会被后续报牌打断，也不堆积过期发言。
5. 联机电脑仍使用服务器内置策略，不因开启发言设置而调用大模型。

## 对局节奏

- 舒缓、标准、快速分别调整电脑和托管的行动等待，语速另外设置。
- 单人设置即时生效；联机房主在创建或等待房间统一选择节奏。
- 真人操作时限和规则响应窗口保留。模型等待上限分别为 40、25、12 秒，超时由内置电脑代打；不会加快模型接口本身。

## 下载与升级

- APK 保留服务器地址设置，填游戏服务地址（不是 AI 的 `/v1` 地址），测试后保存。好友连接同一服务器即可联机。
- 飞牛 `deskpark-0.3.6.fpk` 依赖 Node.js 22，沿用端口与默认 AI 配置；升级会结束当前内存联机房间。
- APK 为调试签名 Alpha 包，FPK 为未签名手动安装测试包。附件由 GitHub Actions 构建，附 SHA-256 校验文件。
- 验证包括规则与多人数整局模拟、信息隐藏、电脑计时、语音桥参数与 AI 朗读回归、手机横竖屏、双端联机及 FPK 服务测试。Android 由 Actions 构建，具体手机音色和扬声器效果需实机试听。
